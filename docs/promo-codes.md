# Промокоды

POST /api/orders/quote принимает products, bundles, promoCode и возвращает subtotalPrice, discountAmount, totalPrice в гривнах. Цены и наличие берутся из базы. Создание заказа повторяет проверку и требует expectedTotal при промокоде; изменение суммы возвращает 409.

Расчёт в копейках, округление скидки один раз на весь заказ. Минимум 300 грн до скидки. Доставка не включается. Общий код без лимита использований. Существующий заказ и повтор оплаты сохраняют первоначальную скидку даже после истечения акции.

Команды в каталоге сервера:

```sh
node scripts/managePromoCode.js prepare KINTSUGI5
node scripts/managePromoCode.js status KINTSUGI5
# Только при запуске кампании:
node scripts/managePromoCode.js activate KINTSUGI5
node scripts/managePromoCode.js disable KINTSUGI5
```

prepare создаёт неактивный код 5%, не изменяя существующий. activate запускает ровно 21 × 24 часа и не продлевает уже запущенную акцию при повторе. Никаких отправок писем и автоматической активации при деплое. Сначала развернуть сервер, затем клиент. Проверка оплаты на реальном платеже отдельно.
