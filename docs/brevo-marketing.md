# Рассылки Kintsugi через Brevo

Подготовлено подключение и read-only проверка аккаунта. Аккаунт подключён; домен и отправитель подтверждены. Текущие письма о заказах и регистрации продолжают использовать Gmail; автоматического импорта адресов, создания кампаний или отправки на старте сервера нет.

## Подключение

1. Зарегистрировать бесплатный аккаунт на https://www.brevo.com/ и подтвердить почту.
2. В настройках отправителей добавить домен kintsugi.org.ua. Внести выданные Brevo DNS-записи подтверждения, DKIM и DMARC. Использовать существующий принимающий почту адрес на своём домене; новый адрес сначала создать у своего почтового провайдера. Не выдумывать значения DNS и не создавать вторую DMARC-запись.
3. Подтвердить отправителя и записать его числовой ID. Создать API key (не SMTP key) и добавить в серверный .env:

```dotenv
BREVO_API_KEY=
BREVO_SENDER_ID=
```

Не передавать API key в браузер, Git или сообщения. Проверить:

```sh
npm run marketing:check
```

Команда выполняет только GET account и GET senders: печатает сведения о тарифах/credits и статус выбранного отправителя без ключей, адреса аккаунта и личных данных. credits — значение провайдера, не обещание доступной суточной квоты. senderActive не заменяет проверку аутентификации домена.

## Первая кампания — отдельный этап

Используем Marketing > Email campaigns, а не transactional SMTP. Brevo обрабатывает отписки и отчёты о доставке. Подготовить подтверждённую аудиторию, исключив отписавшихся; наличие адреса в заказе само по себе не является подтверждением подписки. Импорт не должен возвращать отписавшихся в активные подписчики.

Free: до 300 отправок в день; Согласованный темп — до 200 писем в день: для 775 получателей четыре партии (200 + 200 + 200 + 175), без учёта исключённых адресов. Не запускать весь список с расчётом на автоматическую остановку на 200. После дневного лимита остаток кампании повторно ставится в очередь через Requeue; бесплатный тариф не обещает автоматическое завершение за три дня. Проверить актуальный лимит в аккаунте.

Перед отправкой: развернуть и проверить промокод, подготовить украинский текст и ссылку отписки, проверить отправителя/домен и тестовое письмо. Перед запуском первой партии активировать KINTSUGI5 на сервере; сообщить в письме точную дату окончания. У получателей поздних партий останется меньше 21 дня — срок общий. Отправку всей кампании выполнить только после утверждения текста и аудитории владельцем.
